# Решение проблем (RU)

## Диагностика за 30 секунд

```bash
cd python && python -m ae_mcp --status
```
Покажет: найден ли `AfterFX.exe`, найден ли `ae_bridge.jsx`, где почтовый ящик,
жив ли heartbeat, хвост `bridge.log`.

---

## `ping` возвращает BRIDGE_NOT_ALIVE

1. **AE вообще запущен?** Открой After Effects (любой проект).
2. **Галка безопасности**: `Edit > Preferences > Scripting & Expressions >`
   **Allow Scripts to Write Files and Access Network** → включить → **перезапустить AE**.
   Без неё мост не может писать файлы ответов — это причина №1.
3. **Мост загружен?** В AE: `File > Scripts > Run Script File...` → выбрать
   `bridge/ae_bridge.jsx`. Если сработало — проблема была в автозапуске:
   переустанови (`install.py`), файл должен лежать в
   `%APPDATA%\Adobe\After Effects <ver>\Scripts\Startup\ae_bridge.jsx`.
4. **AE_MCP_EXE**: если AE установлен нестандартно, укажи путь к
   `AfterFX.exe` в переменной окружения сервера.
5. Модальный диалог (например «N files are missing») блокирует все скрипты.
   Закрой его. Диалог чаще всего прячется за главным окном.

## Все вызовы висят и отваливаются по TIMEOUT

- AE занят длинным рендером/предпросмотром — подожди или увеличь `timeout_s`.
- Диалог открыт (см. выше).
- Посмотри `%TEMP%\ae-mcp-bridge\bridge.log` и папки `commands/`, `results/`:
  - запрос лежит в `commands/`, а ответа нет → AE не исполняет скрипты (галка/диалог);
  - ответ появился, но клиент уже отвалился → увеличь таймаут (`AE_MCP_TIMEOUT`).
- Проверь, что `AE_MCP_RUNTIME_DIR` (если задан) одинаковый у сервера и у AE.
  Мост пишет свой путь в `heartbeat.json → runtime_dir`.

## «No active composition»

Инструменты с необязательным `comp` ищут активный комп. Открой комп в AE или
передавай `comp` (имя или id) явно. Если в проекте ровно один комп — он
подставится автоматически.

## Свойство не найдено (BAD_PATH)

Сначала посмотри точные имена через `prop_list` (или `effect_get_params`).
Путь пишется сегментами: `Transform.Position`, `Effects.Gaussian Blur.Blurriness`.
Регистр не важен, поддерживаются matchName и отображаемые имена.

## Эффект «Cannot add effect»

`effect_list_installed {name_contains: "..."}` → возьми точный `match_name`
(например `ADBE Gaussian Blur 2`). На AE младше 2024 список приходит из
встроенного справочника — имя эффекта в твоей локализации может отличаться,
matchName — никогда.

## frame_render: NOT_SUPPORTED

`comp.saveFrameToPng` появился в AE 2023. На старых версиях используй
`render_start` с PNG-шаблоном вывода.

## Рендер стартовал, но файлов нет

- `render_start` возвращает `status` и пути; статус `error` → смотри
  `%TEMP%\ae-mcp-bridge\bridge.log` и лог самого AE.
- Путь вывода должен содержать расширение (`.png`, `.mov`, ...).
- Шаблон Output Module: `format` ищет установленный шаблон по имени
  (`PNG`, `ProRes 422`, `H.264`, `Lossless`, ...). В русской локализации AE
  имена шаблонов могут отличаться — задай свой через `output_template`
  или создай шаблон в AE заранее.

## Несколько запущенных AE (AfterFX.exe -m)

Протокол рассчитан на один активный инстанс (использует одно-инстансовую
доставку `-r`). Для параллельной работы подними второй MCP-сервер с другим
`AE_MCP_RUNTIME_DIR` и подключи к агенту как отдельный сервер.

## Антивирус/корпоративные политики блокируют запись в %TEMP%

Задай `AE_MCP_RUNTIME_DIR` на путь внутри разрешённой папки (например
`D:\ae-mcp-bridge`) и перезапусти сервер И AE (мост читает переменную при старте).

## AE пишет «After Effects error: ...» при запуске Startup-скрипта

Мост не должен дублироваться. Закрой AE, проверь, что в `Scripts\Startup\`
лежит ровно один `ae_bridge.jsx` (актуальная копия из репозитория), и запусти AE.

## Клиент (Claude Desktop и т.п.) не видит инструменты

- Конфиг валиден? `python` доступен в PATH для клиента? Полный ли путь?
- Перезапусти клиент после правки конфига.
- Запусти сервер вручную: `python python/ae_mcp/server.py` — в stderr должно
  появиться `[ae-mcp] 94 tools ...` (94 = 95 минус выключенный `run_script`).
- Для HTTP-режима endpoint — `http://127.0.0.1:8678/mcp`, и клиент должен
  поддерживать streamable HTTP.
